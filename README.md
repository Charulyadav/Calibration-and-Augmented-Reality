# EXECUTABLES

After building, bin/Release/ contains three programs:

    detectCorners.exe   - Tasks 1-3: detect corners, collect calibration
                          images, run calibration, save intrinsics
    detectPose.exe      - Tasks 4-6 + hide-target extension: pose estimation,
                          3D axes, virtual jug, and target hiding
    detectFeatures.exe  - Task 7: Harris corner detection in a live stream

5. Copy the Release OpenCV DLL into bin/Release if not already there:
       copy C:\Users\Charul\Downloads\opencv\build\x64\vc16\bin\opencv_world*.dll bin\Release\

# RUNNING THE PROGRAMS

--- Calibration (Tasks 1-3) ---
    .\bin\Release\detectCorners.exe

    Controls:
      q  quit
      s  save the current frame's corners as a calibration image
      c  run calibration (needs >= 5 saved images)
      w  write intrinsics to intrinsics.yml

    Workflow: hold the board at varied angles, press 's' on 5+ good
    detections, press 'c' to calibrate, then 'w' to save intrinsics.yml.

--- Pose, Axes, Virtual Object (Tasks 4-6 + extension) ---
    .\bin\Release\detectPose.exe

    Requires intrinsics.yml in the working directory (from calibration).
    Controls:
      q  quit
      h  toggle "hide target" mode (extension) on/off

    Shows the virtual jug floating above the board; 'h' hides the
    checkerboard so the jug appears to sit on a clean surface.

--- Robust Features (Task 7) ---
    .\bin\Release\detectFeatures.exe

    Controls:
      q  quit
      s  save the current frame
    Use the Threshold trackbar to experiment with corner sensitivity.

# EXTENSIONS

1. Hiding the target: a mode (toggled with 'h' in detectPose) that covers
   the checkerboard with a fill color sampled from the surrounding surface,
   so the virtual jug appears to rest on a clean surface instead of a
   fiducial marker.

2. Multi-camera calibration comparison: I calibrated two cameras — my
   laptop webcam and my Android phone camera (connected via Windows Phone
   Link) — and compared their intrinsic parameters, distortion, and
   reprojection error. Details and the comparison table are in the report.

   To reproduce the phone calibration: connect the Android phone via Phone
   Link (used as a camera source), change the VideoCapture index in
   detectCorners.cpp to the phone's device index, and run the normal
   calibration workflow.
